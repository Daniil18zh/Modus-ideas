# 💡 Модус Идеи

Telegram Mini App для ГК «Модус Трейд»: сотрудники и клиенты сообщают о проблемах, команда предлагает решения на доске в стиле Trello, руководитель выбирает лучшее, а участники зарабатывают **Модус-коины** и меняют их на премии, выходные, дни к отпуску и путёвки.

Работает целиком на **бесплатном тарифе Cloudflare**: Workers, D1 (SQLite), Static Assets и Cron. Отдельный сервер не нужен.

Продуктовая и техническая концепция по ТЗ лежит в [docs/CONCEPT.md](docs/CONCEPT.md).

## Что умеет

| Для кого | Возможности |
|---|---|
| **Собственник** | Регистрируется по одноразовой ссылке-приглашению от администратора, в рабочей группе состоять не обязан. Помощник собственника готовит доклад за 7, 30 или 90 дней: нерешённые и решённые проблемы, выводы («что требует внимания») и оценку каждого сотрудника по фактам — «Решает проблемы», «Участвует», «Держит просрочку», «Нет активности», «Новый». Доклад виден в приложении, отправляется в Telegram по кнопке и автоматически каждый понедельник. Видит раздел «Команда»: вклад каждого сотрудника (обращения, решения, задачи в работе, закрытые и просроченные) и живую ленту событий. Получает уведомления о новых обращениях, решениях, выборе победителя и закрытии задач. Остальные права — как у администратора. |
| **Сотрудник** | Вход через Telegram без паролей. Создаёт обращение двумя кнопками: «Сделаю сам» (сразу становится исполнителем, после приёмки получает всю награду) или «Попросить команду» (карточка уходит на доску, можно анонимно). Предложенное решение прикладывается сразу. Перед отправкой видит похожие обращения. Подключается к карточкам, предлагает решения и голосует за чужие, комментирует. Сдаёт задачу на проверку. Смотрит баланс, уровень, достижения и рейтинг, меняет коины на награды. |
| **Руководитель** | Выбирает лучшее решение: автор решения получает награду и становится исполнителем. Меняет приоритет, срок, награду и исполнителя. Принимает работу и начисляет коины, может вернуть на доработку или отклонить. Смотрит аналитику. |
| **Администратор** | Подтверждает и отклоняет обмены коинов (при отказе коины возвращаются). Управляет QR-точками и плакатами, ролями и отделами, вручную начисляет коины. Отключает и удаляет сотрудников (по желанию — с исключением из рабочей группы; история сохраняется, удалённого можно восстановить). В «Настройках» меняет название компании, награды и сроки по приоритетам, бонусы, правила «горящих» задач, включает и выключает утреннюю сводку и приём обращений по QR, отвязывает рабочую группу. Настраивает категории, ответственных (маршрутизация) и магазин наград. |
| **Клиент** | Сканирует QR, без регистрации описывает проблему и получает ссылку для отслеживания статуса. |
| **Бот** | Уведомляет о новых обращениях в группе и в личке ответственных, о выборе победителя, о начислениях и решениях по обмену. Каждое утро публикует сводку: «горящие» и просроченные задачи. |

### Модус-коины: правила

| Действие | Коины |
|---|---|
| Ваше решение выбрано лучшим | награда задачи: 30 / 60 / 120 МК (низкий / средний / высокий приоритет) |
| Внедрили решение, руководитель принял | +50% награды |
| Закрыли до дедлайна | +20 |
| Предложили решение (каждому участнику, когда задача закрыта) | +5 |
| Сообщили о реальной проблеме (когда она решена) | +10 |
| 🔥 «Горящая» задача: за 48 ч никто не взялся | награда растёт на 20% в сутки, максимум ×2 |

Уровни: Новичок → Участник (100) → Специалист (300) → Эксперт (700) → Мастер (1500) → Легенда (3000). Магазин по умолчанию: обед (80), мерч (150), премия 3 000 ₽ (300), выходной (400), +1 день к отпуску (500), премия 10 000 ₽ (900), путёвка в тёплые страны (6000). Цены и состав администратор меняет прямо в приложении.

## Развёртывание на Cloudflare (≈15 минут)

Понадобятся Node.js 18+, бесплатный аккаунт Cloudflare и Telegram.

### 1. Бот

1. В [@BotFather](https://t.me/BotFather) выполните `/newbot` и сохраните токен.
2. Узнайте свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)): так вы станете администратором.

### 2. Cloudflare

```bash
npm install
```

```bash
npx wrangler login
```

```bash
npx wrangler d1 create modus-ideas
```

Скопируйте `database_id` из вывода в `wrangler.toml`, а в `ADMIN_IDS` впишите свой Telegram ID.

```bash
npm run db:init:remote
```

Если база создана до появления роли собственника, добавьте колонку (один раз):

```bash
npx wrangler d1 execute modus-ideas --remote --command "ALTER TABLE users ADD COLUMN is_owner INTEGER NOT NULL DEFAULT 0"
```

```bash
npx wrangler secret put BOT_TOKEN
```

```bash
npx wrangler secret put WEBHOOK_SECRET
```

`WEBHOOK_SECRET` — длинная случайная строка, только латиница, цифры, `_` и `-`.

```bash
npm run deploy
```

Wrangler выведет адрес вида `https://modus-ideas.<ваш-поддомен>.workers.dev`.

### 3. Подключение бота

Откройте в браузере `https://modus-ideas.<ваш-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>`. Эта ссылка регистрирует webhook, кнопку меню «Модус Идеи» и команды бота.

Для красивых ссылок на карточки в группе: в @BotFather выполните `/newapp`, выберите бота, укажите URL приложения и короткое имя (например, `board`). Впишите это имя в `APP_SHORT_NAME` в `wrangler.toml` и снова выполните `npm run deploy`.

### 4. Вход через рабочую группу

1. Откройте бота в личке, нажмите «Открыть приложение»: вы войдёте как администратор (ваш ID указан в `ADMIN_IDS`). Других администраторов и руководителей назначайте в «Управление → Люди».
2. Добавьте бота в рабочую группу компании и отправьте там `/bind` (команду принимают только от ID из `ADMIN_IDS`).
3. Сделайте бота администратором группы с правом «Закреплять сообщения»: бот сам закрепит наверху группы сообщение с кнопкой входа (или отправьте `/app`). Кнопка открывает приложение прямо из группы — для этого в @BotFather включён главный Mini App (`Bot Settings → Configure Mini App`) и в `wrangler.toml` стоит `MAIN_APP = "1"`.
4. Собственника пригласите в «Управление → Люди → Создать ссылку-приглашение».
5. Готово. Войти может только участник этой группы. Регистрация происходит автоматически при первом открытии. Кто вышел из группы, теряет доступ (проверка каждые 6 часов). Команда `/app` в группе публикует кнопку входа.

### 5. QR-коды для клиентов

«Управление → QR-коды → Создать точку» (офис, объект, сервисная машина), затем «🖨 Плакат». Обращения с каждой точки считаются в аналитике отдельно.

## Локальный запуск и демо

```bash
npm install
```

```bash
cp .dev.vars.example .dev.vars
```

```bash
npm run db:init
```

```bash
npm run db:seed
```

```bash
npm run dev
```

Откройте http://127.0.0.1:8787. При `DEMO_MODE=1` можно войти без Telegram под демо-пользователями: Анна (админ), Игорь (руководитель), Мария, Пётр, Ольга (сотрудники). QR-форма клиента: http://127.0.0.1:8787/c/?p=office-msk

Для показа на хакатоне можно временно включить демо и на проде: `DEMO_MODE = "1"` и `npm run db:seed:remote`. Демо-вход работает только для синтетических пользователей с ID 1000–1999, но **после показа всё равно выключите его**: иначе кто угодно сможет войти под демо-руководителем.

> На Windows не кладите проект в папку с очень длинным путём: `wrangler dev` хранит локальную базу во вложенных папках и упирается в лимит путей Windows (260 символов).

## Структура

```

public/app.css     спокойная тема, подстраивается под светлую или тёмную тему Telegram
public/c/          публичная QR-форма и страница статуса для клиентов
public/poster.html плакат с QR для печати
schema.sql         схема D1 и справочники по умолчанию
seed-demo.sql      синтетические демо-данные
```

## Известные ограничения MVP

- Вложения (фото, файлы) не реализованы. Следующий шаг — Cloudflare R2 (бесплатный тариф до 10 ГБ, но нужна привязка карты).
- Интеграции с Битрикс24 и 1С описаны в концепции, но не реализованы.
- Клиент узнаёт о статусе по ссылке. SMS и e-mail уведомлений нет.
- Анонимность «мягкая»: автор хранится в базе, чтобы начислить коины и прислать уведомление, но в приложении не показывается никому, включая руководителей.
